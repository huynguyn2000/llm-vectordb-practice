**Goal:** A thin, local-first Mem0 memory layer (`remember`/`recall`) configured for Ollama + Chroma, with a pure unit-testable config helper and a best-effort demo.

**Architecture:** `memory/` package: `config.py` (pure `build_memory_config()` dict — the no-infra testable core), `store.py` (lazy `mem0` import; `build_memory`/`remember`/`recall`). `demo.py memory` runs a store-then-recall scenario. Opt-in `memory` extra.

**Tech Stack:** Python 3.11+, mem0ai (opt-in extra), local Ollama, Chroma, pytest.

**Spec:** `docs/superpowers/specs/2026-08-10-mem0-memory-design.md`

## Global Constraints

- `build_memory_config() -> dict` is a PURE function (no mem0 import): local Ollama LLM + Ollama embedder + Chroma vector store, models/host from env (`LLM_MODEL`/`EMBED_MODEL`/`OLLAMA_BASE_URL`).
- mem0 imported LAZILY inside `store.py` functions; `import memory.config` and `import memory.store` must work WITHOUT mem0ai installed.
- `mem0ai` in a `memory` extra, NOT base. Add `memory`, `memory.tests` to setuptools packages.
- The config unit test needs NO infra and NO mem0ai (pure dict shape).
- mem0 API is version-sensitive — the code targets `Memory.from_config(config)`, `mem.add(messages, user_id=...)`, `mem.search(query, user_id=...)`; if the installed mem0ai differs (config key names, method signatures/return shape), ADAPT and note it (Ragas/Docling posture). A mem0ai install conflict or slow local extraction is documented-not-blocking.

import os


def build_memory_config() -> dict:
    base = os.getenv("OLLAMA_BASE_URL", "http://localhost:11434")
    return {
        "llm": {
            "provider": "ollama",
            "config": {
                "model": os.getenv("LLM_MODEL", "llama3.2"),
                "ollama_base_url": base,
            },
        },
        "embedder": {
            "provider": "ollama",
            "config": {
                "model": os.getenv("EMBED_MODEL", "nomic-embed-text"),
                "ollama_base_url": base,
            },
        },
        "vector_store": {
            "provider": "chroma",
            "config": {"collection_name": "mem0", "path": ".mem0_chroma"},
        },
    }

- [ ] **Step 4: `memory/store.py`**

```python
"""Thin Mem0 wrapper. mem0 is imported lazily so this module loads without the
`memory` extra installed."""

from memory.config import build_memory_config


def build_memory():
    """Construct a local Mem0 Memory. Raises a clear error if mem0ai is absent."""
    try:
        from mem0 import Memory
    except ImportError as exc:
        raise ImportError(
            "mem0 is not installed — install the memory extra: pip install -e '.[memory]'"
        ) from exc
    return Memory.from_config(build_memory_config())


def remember(mem, user_id: str, messages) -> None:
    """Store messages (a string or a list of {role, content}) for a user."""
    mem.add(messages, user_id=user_id)


def recall(mem, user_id: str, query: str) -> list[str]:
    """Return memory strings relevant to the query for a user."""
    result = mem.search(query, user_id=user_id)
    # mem0 returns either {"results": [{"memory": ...}, ...]} or a list; handle both.
    rows = result.get("results", result) if isinstance(result, dict) else result
    return [r.get("memory", str(r)) if isinstance(r, dict) else str(r) for r in rows]
```
